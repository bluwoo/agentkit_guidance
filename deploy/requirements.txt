# =============================================================================
# AgentKit Wizard — runtime dependency manifest (single-process image)
# =============================================================================
#
# This file is the DIRECT-dependency manifest for the docker image. It is a
# faithful, verbatim reproduction of vendor/hermes-agent/pyproject.toml
# `[project].dependencies` (Hermes 0.21.3), with three deliberate, documented
# reconciliations on top:
#
#   (A) ASGI layer pinned to Hermes's OWN exact web-server pins.
#       Hermes core declares fastapi/uvicorn/python-multipart as RANGES
#       (>=x,<1). The exact, Hermes-validated pins for actually running a
#       FastAPI+uvicorn server live in the `web` extra:
#           fastapi==0.133.1, uvicorn[standard]==0.41.0,
#           starlette==1.3.1, python-multipart==0.0.32
#       We adopt those exact pins here (the shim runs uvicorn and imports
#       starlette.middleware.base directly) instead of floating ranges.
#       starlette==1.3.1 also carries the CVE-2026-48710 (BadHost) fix.
#
#   (B) OpenTelemetry pinned to Hermes's `otlp` extra exact pins (1.39.1).
#       The shim lazy-imports OTLPSpanExporter when OTEL_EXPORTER_OTLP_ENDPOINT
#       is set; opentelemetry-api/sdk are imported at module load.
#
#   (C) volcengine is SHIM-ONLY (not in Hermes). It backs the APMPlus V4
#       request-signing client, which imports it lazily inside a function, so
#       the service boots fine without it; we ship it so the observability
#       panel can actually sign requests.
#
# Provider extras (anthropic, exa, firecrawl-py, fal, edge-tts, modal, voice,
# wake, messaging, ...) are intentionally NOT installed: Hermes lazy-installs
# them via tools/lazy_deps.py on first use, and the shim never reaches them.
#
# Python: image uses python:3.12-slim; satisfies Hermes requires-python
# ">=3.11,<3.14". pydantic is pinned to 2.13.4 (pulls pydantic-core 2.46.4):
# pydantic-core 2.41.5 segfaults on the OpenAI Responses-API path driven from a
# non-main thread.
# =============================================================================
