什么是镜像仓库

镜像仓库（Container Registry，CR）提供安全高可用的容器镜像、Helm Chart 等符合 OCI 标准的云原生制品托管服务，方便企业用户管理容器镜像和 Helm Chart 的全生命周期。

什么是智能体身份和权限管理平台

智能体身份和权限管理平台是火山引擎提供的一站式身份及权限管理平台，专为 AI Agent 和工具应用设计，旨在解决从用户到智能体，再到后端工具（User -> Agent -> Tool）整条链路中的身份认证、权限控制和安全凭证管理问题。

什么是[BASE-ADK]

[BASE-ADK]（Volcengine Engine Agent Development Kit）是火山引擎推出的智能体开发套件，旨在为开发者提供构建、部署和管理智能体应用的全套解决方案。它基于模块化设计理念，将复杂的智能体开发过程分解为可组合的组件，让开发者能够专注于业务逻辑而非底层技术细节。

什么是Viking记忆库

Viking 长期记忆是火山引擎推出的一款标准化长期记忆产品，核心目标是为 AI 应用提供 持久记忆能力。 它能够从对话和业务数据中自动抽取关键事件与用户画像，并以结构化形式保存，支持精准检索与高效调用，从而帮助 AI 在多轮交互中保持上下文连贯和个性化体验。

什么是Mem0记忆库

火山引擎记忆库 Mem0 提供的是托管型的记忆项目服务，兼容开源 Mem0 记忆系统，通过构建企业级记忆基础设施，助力人工智能应用实现从单次对话到持续交互的能力升级，为个性化智能服务奠定技术基础，为大型语言模型应用程序提供持久化记忆层解决方案。

什么是Viking知识库

Viking知识库是Viking团队在火山引擎上架的知识库RAG服务产品，基于VIkingDB向量库实现百亿级规模存储与毫秒级检索的能力，提供“文档管理-语义检索-智能对话”的一体化服务，支持多模态存储格式，同时包括结构化和非结构化数据，适用于法律、教育、企业文档管理等多个场景。
