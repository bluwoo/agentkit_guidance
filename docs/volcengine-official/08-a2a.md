## 概念

A2A（Agent-to-Agent）是 Google 提出的开放协议，实现不同框架/供应商 Agent 间互通协作。**A2A 中心（Registry）** 统一管理平台内外 A2A Agent 通信，基于底层网关提供标准 A2A 协议的同步/异步通信能力。

两大能力：
1. **空间内注册 A2A 智能体**：可一键把 Runtime 上的 A2A 智能体注册，或导入 JSON / AgentCard 地址注册外部智能体。
2. **智能体发现与通信**：在智能体空间中通过多维度筛选或语义检索（自动语义索引）识别调用意图，A2A Client 对 AgentCard 动态发现，基于 A2A 协议同步/异步通信。

## 操作流程

来源：quick-access-a2a-center
1. **创建智能体空间**（A2aSpace）：可开启/关闭语义检索。
2. **注册智能体**（A2aAgent）：导入 JSON 文件或填写 AgentCard 地址；支持公私网服务地址变更。
3. **版本管理**：管理智能体版本；查看/更新智能体 JSON 与 AgentCard 地址。
4. **注销**：注销智能体；删除智能体空间。

## 集成方式

- 创建 Runtime 时在"注册到 A2A 空间"选择空间，注册地址随网络访问方式自动选公网/私网。
- 注册完成后，其他智能体应用可将其作为 A2A Agent 资源调用；在 ArkClaw 企业版应用中心注册后，用户可通过自然语言/@ 命令调用。
