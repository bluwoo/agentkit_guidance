## 计费总览

费用 = **资源用量费用** + **网关实例费用**，各计费项独立计量、分别出账。

**重要变更（2026-08-31 起）**：原网关计费与运行时计费，改为按网关实例（共享/专属）、Runtime、MCP（MCP 服务/工具集）实际用量计费。购买网关实例需账户可用余额 > 100 元。

## 网关实例费用

**共享网关** = 实例费 + 数据处理费（数据处理暂免费）
- 每账号每地域免费额度：Runtime 2 个；MCP 服务+工具集合计 2 个。
- 共享网关实例：**1 元/个/小时**（超出免费额度按实际时长计）。
- 存量资源（2026-08-31 前创建）默认升级为共享网关模式，但**不自动下单**，不立即计费；只有在该地域新建资源时才自动下单共享网关实例并开始计费。

**专属网关** = 实例费 + 公网流量费 + 数据处理费 + 工具索引费（仅语义检索）
- 公网流量 0.8 元/GB；数据处理 0.042 元/GB；工具索引 0.014 元/万个/小时。

- Runtime 专属网关 small_x1 + MCP 专属网关 small_x1 + 部署模式 MCP 服务 + 语义检索，24h ≈ **577.48 元**。
