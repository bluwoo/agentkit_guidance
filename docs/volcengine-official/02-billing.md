## 计费总览

费用 = **资源用量费用** + **网关实例费用**，各计费项独立计量、分别出账。

**重要变更（2026-08-31 起）**：原网关计费与运行时计费，改为按网关实例（共享/专属）、Runtime、MCP（MCP 服务/工具集）实际用量计费。购买网关实例需账户可用余额 > 100 元。

## 网关实例费用

**共享网关** = 实例费 + 数据处理费（数据处理暂免费）
- 每账号每地域免费额度：Runtime 2 个；MCP 服务+工具集合计 2 个。
- 共享网关实例：**1 元/个/小时**（超出免费额度按实际时长计）。
- 存量资源（2026-08-31 前创建）默认升级为共享网关模式，但**不自动下单**，不立即计费；只有在该地域新建资源时才自动下单共享网关实例并开始计费。

**专属网关** = 实例费 + 公网流量费 + 数据处理费 + 工具索引费（仅语义检索）
- 公网流量 0.8 元/GB；数据处理 0.042 元/GB；工具索引 0.014 元/万个/小时。

## 套餐包（2026-10-29 新增，预付费抵扣）

套餐包是预付费资源抵扣方式，用于抵扣 **Runtime / Sandbox / MCP** 资源产生的 vCPU 与内存费用；相比按量计费通常有更高折扣，适合用量相对稳定的场景。

| 套餐包类型 | 规格（标准额度） | 适用资源 | 抵扣系数 |
|---|---|---|---|
| vCPU 算力包 | 10,000 / 50,000 / 200,000 标准 vCPU·时 | Runtime / MCP | 1.00 |
| vCPU 算力包 | 同上 | Sandbox | 0.42 |
| 内存包 | 20,000 / 100,000 / 400,000 标准 GB·时 | Runtime / MCP | 1.00 |
| 内存包 | 同上 | Sandbox | 0.66 |

- 两类套餐包独立售卖、独立抵扣，可按核存比灵活组合，无需按固定核存比购买。
- 有效期内优先用套餐包额度抵扣对应计费项；未超出额度不产生对应额外计算费用。
- 抵扣额度 = 实际资源用量 × 对应资源类型抵扣系数；具体价格、成交价与抵扣系数以控制台下单页与最新公告为准。
- **边界**：套餐包抵扣的是资源 vCPU/内存用量，**不是模型 Token 包**；模型调用 Token 费仍由模型提供商按 Token 计。
- 来源：`package-overview` / `purchase-package` / `renew-package` / `view-package-details`（2026-10-29）。

## 金额概览（2026-11-17 新增）

计费管理 > 金额概览：查看账期内已产生费用、本月预测支出与费用构成，支持按组件/计费项拆分、按日/周/月切换粒度，金额明细可导出。

- 汇总指标：账期应付金额（已产生应付估算）、本月预测金额（按当前用量预测本月 1 日至月末）。
- 历史账期不提供未来预测（未来预测置灰，本月预测显示 `--`）。
- IAM 用户需主账号先授予 AgentKit 相关权限才可查看费用明细；图表金额单位人民币元，时间口径北京时间（UTC+8）。
- 来源：`view-cost-details`（2026-11-17）。
